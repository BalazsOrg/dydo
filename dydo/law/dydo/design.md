## dydo-design-shared-language

Name things precisely and use each name for one meaning, so the user and agents mean the same things by the same terms.

description: This is the same idea as Matt Pocock's domain modelling. And in fact the idea of 'naming things' is as old as language. And the idea of if you name something you have power over it is very true. If a certain recurring thing has a precise name associated with it is half conquered. Anchor phrases are similar ideas. 'Axiom', 'Principle', 'Guard' all have specific meanings within Dydo and with them we nail down what we speak about without having to describe them each time

cites: [dydo-aligned-intent](./axioms.md#dydo-aligned-intent)
