# dydo Case Studies

A case study is an optional markdown file in git next to the law. It captures a Question, grilling decision or idea that shaped the law and links its Linear origin. Agents prepare one when a call looks precedential; Balazs approves it ([DECIDED, A6](https://linear.app/bodnar-balazs/issue/DYD-1078#comment-9ac278c0-00f3-4688-9971-2693bfc14e38)).

No case studies are enacted here.
