# Too big for one agent

## Too big: re-cut

Arrivals:

- On `too big, re-cut` from your crew, you are the cutter: decide whether the unit gets children, and never promote yourself.

Exits:

- Cut only coherent units too big for one agent or able to run in parallel, never to pass work down.

## Save, resume and end

- Save the returned hop's SHA on it and resume each child from there; end resolved once the children are staffed, or escalated by sending a ticket too big for you to your officer as `too big, re-cut`.
